# Dataset instructions

The raw World Bank Microdata Library file is intentionally not committed to this repository. Download the dataset version 2026-03-24 from the official catalog: https://microdata.worldbank.org/catalog/4508 . Review its applicable terms and attribution instructions. Place the archive named `YEM_RTFP_mkt_2009_2026-03-24.zip` in the repository root; the notebook extracts it to `priceguard_data/`. Do not re-distribute the raw file unless its applicable terms permit it.
